# Release notes

What changed in each build of the deployed site, keyed by the commit that built it. The
Settings screen's build-information panel shows the build on every deployed copy as `Build
<commit>`, and every recording the site saves carries the same value in its `buildVersion`
field, so a report can say which of these entries it is about. GitHub issue #246 asked for
this file and for that line.

One entry per merge to `main` that deployed, newest first. The heading is the first ten
characters of the merge commit and the date it landed. A wave that did not deploy a new site
has no entry. Entries are written in the player's words; the engineering record is
`DECISIONS.md` and the per-wave ledger.
