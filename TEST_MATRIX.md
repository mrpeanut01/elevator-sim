Unit/property coverage colocates with source (`*.test.ts`); this matrix tracks the *journeys*.

**Every row below was re-measured on 2026-08-24 at `000852a`** by lane M2-MEASURE — read clause by
clause against the test that would satisfy it, and **run** where one exists. The evidence, the

**The rule that governs this file, and the one it has already been broken by once:**
`passing` requires a named test file **and** a watched green run **and** every clause of the scenario
covered. **A row is not upgraded on a test that covers part of its scenario** — that is the
stale-by-omission failure § Z records. Where coverage is partial the row reads `owned` and **names
the missing leg**, so the next lane extends a test instead of rebuilding one.

**Nineteen rows read `planned` before this pass and only four were genuinely uncovered.** Every wrong
status was wrong in the same direction — understated. The live risk in this file today is not
over-claiming; it is a lane reading `planned` and rebuilding a test that already exists.
